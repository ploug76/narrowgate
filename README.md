# Narrowgate

Privacy / data-broker removal helper. It asks for your state first, then only the fields each official opt-out needs, and builds a manual checklist. It also has **Check my info**: paste a credit file, people-search listing, or similar notes and get an offline report.

Nothing is uploaded. No analytics. Sample names (Casey Quinn, Morgan Lee, Riley Chen) are invented.

## Use it

- Live app: https://ploug76.github.io/narrowgate/
- Or open `index.html` in a browser.

## Install as an app

1. Open the live link in Chrome (Android / Windows) or Safari (iPhone).
2. Android/Windows: Install app / Add to Home screen.
3. iPhone: Share → Add to Home Screen.
