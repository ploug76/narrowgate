Limits of this prototype

Sources were retrieved November 7, 2026. A request blocks when its review is older than 90 days. Rules change. This is not a fifty-state legal survey.

There is no account, no payment, and no server. A later production system would need encryption, access control, tenant isolation, consent retention, an audit trail, and a credential plan before any real personal information could be stored. This prototype does not claim to be a secure commercial service.

The execution connector stays off until a separate security, legal, and integration review. Incoming requests for more data are checked against the catalog and are not honored just because a site asked.
